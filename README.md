# Prologue

My first python project. A little game I made while I was learning Pyhton and French (Still Learning).

I'm studying to become a programmer, this was my first step ever taken in february 2026.

# Features
- Turn-based combat system 
- Inventory and shop
- Leveling system (pretty basic)
- 3 different zones (Forest, Village, and Castle)
- Final boss: Dragon
- ZERO AI INVOLVED (Fuck AI and vibe coding)

# How to play
1. Download The archive "RPG.py"
2. Make sure to have Python 3.13 or further in your PC
3. Right click and execute in Python (Or you can run it in your VSCode, Cursor, JetBrains, etc.)

# Important

This game is super fragile, use only numbers or it'll explode (I didn't know how to manage exceptions back then) Excuse me.
